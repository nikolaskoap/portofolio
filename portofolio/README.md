# 🌟 Portofolio Personal Mikail Syafiq Ikhwanudin
**Tema: Minimalist Swiss Editorial × Retro Pixel-Finance & Crypto Arcade**

Website portofolio interaktif premium untuk **Mikail Syafiq Ikhwanudin** (Digital Creative | Technology Enthusiast | Product Explorer). Menggabungkan desain editorial modern ala Linear & Swiss Typography dengan elemen game pixel interaktif bertema finance & crypto (Mario Bros coin blocks, draggable crypto tokens, sound synthesizer, crypto staking vault, dan terminal DEX).

---

## 🚀 Cara Membuka Website
Cukup buka file `index.html` langsung di browser favorit Anda (Google Chrome, Microsoft Edge, Brave, Firefox, dll.):
- Buka folder: `C:\Users\user\Downloads\portofolio\`
- Klik ganda (double click) file **`index.html`**

## 🎮 Fitur-Fitur Interaktif Khusus

1. **🪙 Mario '?' Question Blocks & SATS Spawner**
   - Klik blok tanda tanya `?` di Hero Section atau di Arcade Stage.
   - Karakteristik suara koin Mario klasik disintesis secara real-time via **Web Audio API** (tanpa ketergantungan file MP3 eksternal).
   - Menghasilkan koin Bitcoin/Ethereum melompat dan reward teks melayang `+100 SATS`, yang otomatis menambahkan saldo pada retro HUD di navbar.
   - Setiap 10 koin memicu **Level Up Banner**!

2. **🧲 Koin Kripto Draggable (Dapat Ditarik & Dilempar dengan Fisika)**
   - Koin **₿ Bitcoin** dan **Ξ Ethereum** yang melayang dapat Anda klik dan tarik (drag) ke mana saja di layar.
   - Memiliki inersia/kecepatan lemparan (toss physics) dan memantul di tepi layar.
   - **Crypto Staking Vault**: Jatuhkan koin ke dalam kotak Staking Vault untuk mendapatkan bonus staking 2x lipat!

3. **📈 Draggable Retro Finance Terminal & DEX Swapper**
   - Jendela terminal kripto retro di pojok kanan bawah yang dapat ditarik dan dipindahkan ke mana saja di layar.
   - Dilengkapi **Live Pixel Candlestick/Line Chart** yang bergerak secara real-time untuk pasangan `BTC/USD`, `ETH/USD`, dan `BASE/USD`.
   - **DEX Swap Simulator**: Tekan tombol *SWAP 50 SATS FOR EXP* untuk mensimulasikan transaksi smart contract di Base Network (terhubung ke proyek MiddleKid) lengkap dengan hash transaksi sukses.

4. **🏷️ Sticker Workbench Tray (Tribut Stikerpedia & Percetakan)**
   - Di bagian kiri bawah terdapat dock stiker (Astronaut, Cybercat, Pop Coffee, Retro Badge).
   - Klik stiker untuk menempelkannya langsung ke kanvas website. Stiker dapat digeser, diatur posisinya, atau dihapus secara individual maupun sekaligus (tombol *Reset*).

5. **🕹️ Playable Mario Runner Mini-Stage**
   - Mini-stage interaktif di bagian bawah di mana Anda dapat mengontrol karakter pixel Mikail.
   - Kontrol keyboard: `←` / `→` atau `A` / `D` untuk berlari, `Space` / `W` / `↑` untuk melompat membentur blok koin!

6. **🔊 Web Audio 8-Bit Synthesizer**
   - Tombol toggle suara `🔊` di header untuk menghidupkan / mematikan efek suara retro.

7. **📺 CRT Retro Scanline Mode**
   - Tombol `CRT` di header untuk mengaktifkan filter nostalgia tabung arcade retro dengan garis scanline autentik.

8. **🌓 Dark / Light Mode Switcher**
   - Mode default: **Light Editorial Off-white** (`#F7F7F5`) dengan estetika Swiss Minimalist.
   - Mode gelap: **Deep Obsidian Cyber** (`#0B0E14`) dengan kontras tajam.

9. **📄 Download CV Asli & Kontak Terintegrasi**
   - Tombol *Download CV* langsung mengunduh file `CV_Mikail_Syafiq_Ikhwanudin.pdf`.
   - Tombol salin email dengan notifikasi pop-up pixel toast.
   - Tautan langsung ke WhatsApp (+62 812-2241-6955), email, dan proyek live.

10. **🪟 Interactive Case Study Modal & Lightbox Gallery**
    - Modal inspeksi detail untuk **Fazima Print**, **MiddleKid**, **Stickerpedia**, dan **NGL Paper**.
    - Lightbox resolusi tinggi untuk portofolio cetak & grafis asli (Spanduk Fresora, Logo Fresora, Banner Onisamagiri, Neon Martabak Manis, Analisis Pasar Bitcoin).
